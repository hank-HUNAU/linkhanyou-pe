# MTPE Trainer · 译后编辑实训平台

参考全国机器翻译译后编辑大赛答题模式构建的译后编辑（MTPE）教学实训工具。纯前端、零依赖；可安装到桌面、可离线使用。

> **授权范围**：站点**源代码**采用 MIT 许可（[LICENSE](LICENSE)）；**历届大赛真题语料不在 MIT 授权范围内**（著作权归大赛组委会及相关权利人所有），本仓库与站点仅将其用于**课堂教学与非商业学术研究**。权威表述见 [NOTICE](NOTICE) 与下方「[数据与授权声明](#数据与授权声明)」。

## 站点结构（一级首页 + 三个二级页）

按「**找 → 改 → 测**」三步走组织，登录一次即可在三个二级页之间自由往返（12 小时有效期，超时回首页重登）：

| 层级 | 页面 | 练什么 |
|---|---|---|
| 一级 | `index.html` | 首页：三步走导引 + 我的进度回显 + 学习资源；不承载具体练习 |
| 二级 | `annotate.html` | ① **找** · 标注实训：判断哪里该改，种子对照给出查准 / 查全 / F1 |
| 二级 | `practice.html` | ② **改** · 译后编辑练习：限时 8/15/30 分钟或自由练习，看修订率与逐段对照 |
| 二级 | `pe-exam.html` | ③ **测** · 仿真训练：唯一测评口径，整页独占 + 防作弊 + TER 分与结果画像 |

顶栏（`nav.js`）在首页与三个二级页之间提供 首页 / ① 找 / ② 改 / ③ 测 四段式导航；仿真测评页刻意不挂顶栏，以贴近真实赛场。

## 功能

- **🏷 ① 找 · 标注实训**（`annotate.html`）：按 MQM 标签体系（M1-M9/M0）划选标注机翻错误，种子对照评分（Precision/Recall/F1 + MQM-B 质量分）；组卷支持按 届次 / 赛段 / 方向 / **错误类型** 筛选
- **✍️ ② 改 · 译后编辑练习**（`practice.html`）：在机翻底稿上限时编辑或自由练习，交卷看修订率、逐段对照与参考译文点评
- **🎮 仿真训练**（`pe-exam.html`）：按官方赛场界面还原，90 分钟倒计时、切屏监控、TER 测评口径评分、晋级线判定、Agent 同榜
- **📊 结果画像**：每次交卷生成四项诊断——错误维度分布（M1-M9 归并 5 维，雷达为各维度已改对率）、编辑倾向四象限（精准型 / 过度编辑型 / 保守型 / 鲁莽型）、速度与稳定性、参照系（晋级线 / 历史最好 / Agent 同榜）
- **🔁 训练闭环**：画像指出最弱维度 → 一键推荐练习（直达组卷筛选）→ 错题本（漏检 / 标签判错 / 严重度判偏自动入本）→ 错题回练 → 复测
- **👩‍🏫 教学端**（`teacher.html` / `review.html`，口令登录）：课堂视角切换、评析卡片按 M1-M9 分组、一键导出讲义、校对汇总与仲裁
  —— **仅在本地 / 私有部署提供**：教学端含内部基线、讲评编排与班级数据，为防外泄不在公开站点发布（公开站打开这两页会看到说明页）。本机副本内容完整，口令不变。

## 数据

- 平台**只包含历届大赛真题语料**，不含自编练习题（内置演示任务已移除）
- 历届大赛真题语料（第 1-8 届）经多轮核验与清洗后由训练集管道生成（`corpus.js` / `annotate-data.js` 为生成文件）
- 共 **1402 条 A 级句对**（官方对照表逐句可解析的）：英译汉 1260（第 1–8 届）＋ 汉译英 142（第 5/6/7/8 届决赛）。另有 10 条 B 级"案例摘录"（含德语 5 条）不入库
- 整卷 **20 套**（第 1–6 届历史卷 14 套 ＋ 第 7/8 届与官方模拟赛 5 套 ＋ 官方评析教学卷 1 套），「改 / 测」覆盖第 1–8 届全量
- 机翻底稿覆盖 **8 代引擎**：腾讯翻译君 / 小牛翻译 / 云译科技 → 搜狗翻译 → 腾讯 TranSmart → 火山翻译 → GPT-3.5 → GPT-4o → DeepSeek
- **第 3 届（2020 腾讯 TranSmart）与第 5 届（2022 火山翻译）**：官方只公布了"原文 + 参考译文"，机翻输出从未公开、当年引擎也已不可调用，其 691 条底稿由 DeepSeek-V3 按机翻风格**重构**补齐，界面与卷名一律标注为「重构底稿 / 非官方底稿」；**参考译文仍为官方原文**。补入后**全部 1402 条句对均有机翻底稿**，第 8 届初赛德语 5 条属 B 级「案例摘录」，本就不在平台题库内
- MQM 错误类型参考手册见 `MQM错误类型参考手册.html`

## 说明

- **PWA**：`manifest.json` + `sw.js` 支持「安装到桌面」与离线使用（需以 https 打开，如本 GitHub Pages 站点）；本地双击打开（file://）时功能照常，只是没有离线缓存与安装入口
- **首屏很轻**：语料按 3 片分片加密（`secure.js` 密钥环 + meta 片约 11KB、`s-tasks.js` 324KB、`s-pairs.js` 323KB）。
  登录那一刻只下 11KB；进「改 / 测」只下 tasks 片，进「找」只下 pairs 片。首屏不加载任何密文，全部按需拉取并进 HTTP/离线缓存
- 教师口令仅为前端角色切换，非安全鉴权
- 语料以 AES-GCM 加密存放；登录后本机**只留 32 字节内容密钥**（12 小时有效），明文只在内存里；点「退出」立即清除
- 学生作答数据存于浏览器本地（localStorage），由导出 JSON 交作业
- 纯静态站点，可直接以 GitHub Pages / 本地双击方式运行
