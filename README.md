# MTPE Trainer · 译后编辑实训平台

参考全国机器翻译译后编辑大赛答题模式构建的译后编辑（MTPE）教学实训工具。纯前端、零依赖、离线可用。

## 功能

- **🏷 译后编辑实训**（`index.html` / `annotate.html`）：在机翻底稿上限时编辑，按 MQM 标签体系（M1-M9/M0）标注错误，种子对照评分（Precision/Recall/F1 + MQM-B 质量分）；组卷支持按 届次 / 赛段 / 方向 / **错误类型** 筛选
- **🎮 模拟参赛**（`pe-exam.html`）：90 分钟倒计时、切屏监控、TER 考场口径评分、晋级线判定、Agent 同榜
- **📊 结果画像**：每次交卷生成四项诊断——错误维度分布（M1-M9 归并 5 维，雷达为各维度已改对率）、编辑倾向四象限（精准型 / 过度编辑型 / 保守型 / 鲁莽型）、速度与稳定性、参照系（晋级线 / 历史最好 / Agent 同榜）
- **🔁 训练闭环**：画像指出最弱维度 → 一键推荐练习（直达组卷筛选）→ 错题本（漏检 / 标签判错 / 严重度判偏自动入本）→ 错题回练 → 复测
- **👩‍🏫 教师后台**（`teacher.html`，口令登录）：课堂视角切换、评析卡片按 M1-M9 分组、一键导出讲义（Markdown / HTML）、校对汇总与仲裁（`review.html`）

## 数据

- 历届大赛真题语料（第 1-8 届）经多轮核验与清洗后由训练集管道生成（`corpus.js` / `annotate-data.js` 为生成文件）
- 共 **1421 条句对**：英译汉 1267（第 1、2、3、4、5、6、7、8 届）＋ 汉译英 149（第 5/6/7/8 届决赛）＋ 德译汉 5
- 机翻底稿覆盖 **8 代引擎**：腾讯翻译君 / 小牛翻译 / 云译科技 → 搜狗翻译 → 腾讯 TranSmart → 火山翻译 → GPT-3.5 → GPT-4o → DeepSeek
- MQM 错误类型参考手册见 `MQM错误类型参考手册.html`
