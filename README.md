# 译后编辑实训平台（MTPE Trainer）

面向课堂教学的译后编辑（MTPE）实训平台。纯前端、零依赖，可安装到桌面，也可离线使用。

> 本平台**仅用于教学与非商业学术研究**，详见文末「[许可与使用声明](#许可与使用声明)」。

## 用来做什么

把"译后编辑"拆成三步来练，每一步都能立刻拿到反馈：

| 步骤 | 练什么 | 交卷后看到什么 |
|---|---|---|
| ① 找 | 判断机器译文里**哪里该改**：划选有问题的片段，判定错误类型与严重度 | 查准率 / 查全率 / F1；漏检与过度标注都算错，错题自动入本 |
| ② 改 | 在机器译文底稿上**动手改**：限时练习或自由练习，可存草稿 | 修订率、逐段对照、各维度已改对比例 |
| ③ 测 | 在接近真实工作状态的界面里**限时交卷**：整页独占、切屏计数、禁复制粘贴 | 综合评分，以及错误维度分布 / 编辑倾向 / 速度与稳定性 |

交卷不只给一个分数：平台会把错误按维度归并成画像，指出你**最弱的一环**，据此推荐下一组练习；
错题自动进入错题本，可以回炉重练再复测——形成「测评 — 诊断 — 处方 — 复测」的闭环。

## 使用

- 用浏览器打开站点即可使用；支持「安装到桌面」与离线使用（本地双击打开也行，只是没有离线缓存与安装入口）。
- 语料以**加密**形式存放，需要课程负责人发放的账号解锁；解锁后 12 小时内各模块之间往返无需重复登录，
  点「退出」立即清除本机凭据。
- 学生的作答记录保存在本机浏览器中，可通过导出文件交给老师汇总。
